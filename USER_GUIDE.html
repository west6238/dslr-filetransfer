DSLR 사진 자동 전송 프로그램 사용 설명서

본 설명서는 카메라를 PC에 연결하기만 하면 사진을 자동으로 분류하고 지정된 폴더로 복사해주는 DSLR File Transfer 프로그램의 사용법을 안내합니다.

1. 프로그램 시작하기

설치 및 실행

별도의 복잡한 설치 과정이 필요 없습니다.

  1. 전달받은 압축 파일(.zip)을 원하는 폴더에 압축 해제합니다.
  2. 폴더 내에 있는 DSLR_FileTransfer.exe 아이콘을 더블클릭하여 실행합니다.

💡 시작프로그램 등록 (최초 1회)

프로그램을 처음 실행하면, 컴퓨터(윈도우)가 켜질 때마다 프로그램을 자동으로 켤지 묻는 알림창이 나타납니다.

[예(Yes)]를 선택하시면, 매번 프로그램을 수동으로 켤 필요 없이 백그라운드에서 항상 대기하게 되어 매우 편리합니다. (권장)

2. 기본 화면 및 설정 (UI)

프로그램이 실행되면 컴퓨터 화면 우측 하단 시계 옆(시스템 트레이)에 작은 아이콘이 생깁니다. 아이콘을 클릭하거나 우클릭하여 'Open UI (열기)'를 선택하면 설정 화면이 나타납니다.

주요 설정 항목

  • 저장 폴더: 사진이 저장될 기본 위치를 지정합니다. 기본적으로 내 컴퓨터의 '사진(Pictures)' 폴더로 잡혀 있으며, 버튼을 눌러 원하는 곳으로 바꿀 수 있습니다. 이전에 사용했던 폴더 기록도 화살표를 눌러 쉽게 다시 선택할 수 있습니다.
  • 태그명: 사진을 저장할 때, 저장 폴더 안에 이 '태그명'으로 된 새로운 폴더를 만들어 깔끔하게 정리합니다. (예: 제주도여행, 상품촬영 등)
  • 설정 저장 버튼: 저장 폴더나 태그명을 변경했다면 반드시 '설정(Save Settings)' 버튼을 눌러야 적용됩니다. 누르지 않고 작업을 진행하면 경고창이 나타납니다.

3. 카메라 연결 및 사진 자동 복사

설정이 완료된 상태에서 카메라의 전원을 켜고 USB 케이블로 PC에 연결하면 모든 것이 자동으로 진행됩니다!

  1. 자동 인식: 카메라 연결을 감지하면 프로그램 화면이 자동으로 나타납니다.
  2. 미등록 기기 알림: 본인 카메라가 아닌 처음 보는 기기가 연결되면 보안을 위해 자동 복사가 차단되고 "기기 미등록" 알림이 뜹니다. (본인 카메라라면 UI 설정 화면에서 '기기 등록' 버튼을 눌러 추가해주시면 다음부터는 자동으로 작동합니다.)
  3. 자동 복사: 등록된 카메라라면 자동으로 파일 전송이 시작되며, 화면 하단의 진행률 바(Progress Bar)를 통해 진행 상황을 확인할 수 있습니다.

4. 기타 유용한 기능

🔄 자동 업데이트

프로그램이 켜져 있는 동안 최신 버전이 있는지 4시간마다 스스로 확인합니다. 만약 더 좋고 개선된 버전이 나왔다면 팝업창을 띄워 알려줍니다. '예'를 누르면 번거로운 과정 없이 알아서 최신 버전으로 교체되고 다시 켜집니다.

❌ 프로그램 완전히 끄기

프로그램 창을 닫아도, 다음번 카메라 연결을 기다리기 위해 백그라운드(우측 하단 아이콘)에 계속 숨어있게 됩니다.
프로그램을 완전히 종료하고 싶으시다면, 우측 하단 아이콘을 우클릭한 뒤 'Quit (종료)'를 클릭해 주세요.
