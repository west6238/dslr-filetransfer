--------------------
동작 테스트 확인 

1) `.\.venv\Scripts\python.exe .\app\main.py` -> (확인) 아이콘 뜸
2) `Settings` : `Tag Name` 
	. (app 설치 default) 비어있고 dropdown data-list 항목 기본 제공 ( -> git commit `87bf915` 참조)
	. (사용자) new value 기재 또는 `dropdown`에서 항목 선택 시, 이것을 기본값으로 변경
		- (초기 default - 비어 있음을 제외하고) 기존 항목 값은 `dropdown data-list` 에 append 된다 (중복 제외)
	. " `Tag Name` + text box " 아래 줄에 `YYYY-MM-DD_<tag>` 폴더에 저장` 설명 문구 추가
3) `Settings` : `저장 폴더` 항목 추가
	. widget 추가 : dropdown data-list + folder-selector
	. 기본값 : (app 설치 default) Windows 기본 `사진` 폴더 + (`dropdown data-list` 항목 없음)
	. (사용자) ` folder-selector` 이용하여 저장 폴더 변경하면
		- (사용자 변경) 폴더 path가 `저장 폴더` 항목값으로 사용하고, `dropdown data-list` 항목에 append (중복 제외)
	. 사용자는 `dropdown data-list` 에서 `저장 폴더`을 정할 수 있다.

4)  `Settings` :
	(공통)
		- 등록된 기기는 동일한 설정을 이용한다.
		- `Settings` <div> 에 포함된 `설정` 버튼 누르면 -> `Settings` 설정값 업데이트 되고 -> alert(' 설정값 업데이트되었습니다`) notice를 보여준다.
                - (사용자) `Setting` 항목 변경하고 `설정` 버튼을 누르지 않으면 -> `Settings` 설정값 업데이트 되지 않는다.
		- (사용자) `Setting` 항목 변경하고 `설정` 버튼을 누르지 않은 상태에서 `Settings` <div> 내부에 포함되지 않은 버튼을 클릭하면 alert(' 설정값 저장되지 않은 상태입니다.`) notice 제공
		- notice 제공은 modal window 이어도 되고 `Settings` <div> 맨아래 notice 문구 보여주는 것일 수도 있다.

	. [ USE-CASE ]
		- Camera USB 미연결이고 `main.py` 아이콘 클릭 경우
			. 기록된 설정값 기준으로  `main.py`UI display

		- (미등록 기기 Camera USB 연결 경우) 또는 (미등록 camera USB 연결 경우)
			.   `main.py` UI display 
			. `Setting` : `Auto-fetch on connect` checkbox 는 설정값대로 보여주고, ** 자동 실행은 되지 않는다. **
				-> 기기 등록되어 있지 않음 notice 를 보여준다.
