📸 DSLR FileTransfer 사용 매뉴얼 (v2.1.0)

DSLR FileTransfer 앱을 설치하고 사용하는 방법에 대한 안내서입니다.

1. 설치 방법

[Step 1] 좌측 아래 Windows 시작 로고 클릭 -> Windows PowerShell 검색 후 실행

[Step 2] 아래 코드를 복사(Copy)해서 PowerShell 창에 붙여넣기(Paste)하고 Enter 키를 눌러 압축파일(zip)을 다운로드합니다.

Invoke-WebRequest -Uri "https://github.com/west6238/dslr-filetransfer/releases/download/v2.1.0/DSLR_FileTransfer.zip" -OutFile "DSLR_FileTransfer.zip"

[Step 3] 다운로드된 DSLR_FileTransfer.zip 파일을 바탕화면 등 원하는 폴더로 이동한 후, 압축을 풉니다.

[Step 4] 압축을 푼 폴더로 들어가서 DSLR_FileTransfer.exe 파일을 더블클릭하여 실행합니다.

2. 앱 실행 및 기본 동작

  • 앱(DSLR_FileTransfer.exe)을 처음 더블클릭하여 실행하면, 화면 우측 하단의 Windows 시스템 트레이(숨겨진 아이콘 창)에 카메라 모양의 앱 아이콘이 생성됩니다.
  • 백그라운드 모니터링: 앱 메인 화면(UI)이 닫혀 있더라도, 트레이 아이콘이 켜져 있다면 카메라는 상시 연결 감지 상태를 유지합니다.
  • 앱 종료: 앱을 완전히 종료하려면 시스템 트레이 아이콘을 우클릭한 뒤 QUIT를 선택해야 합니다. 메인 화면의 'X' 버튼을 눌러도 앱은 완전히 종료되지 않고 백그라운드로 전환됩니다.

3. 기기 등록 및 자동 기능 (Auto-fetch)

기기를 앱에 최초 1회 등록해야 자동 기능들을 사용할 수 있습니다.

  • 기기 등록 방법: 앱 UI가 열린 상태에서 카메라 USB를 연결하면 기기가 감지됩니다. 처음 연결된 기기인 경우 화면의 안내에 따라 기기를 등록 목록(Whitelist)에 추가할 수 있습니다.
  • 등록된 기기의 이점: 기기가 정상적으로 등록된 상태여야만 USB 연결 시 사진을 자동으로 가져오는 'Auto-fetch' 기능이 지원됩니다. (미등록 기기는 Auto-fetch가 작동하지 않아 안전합니다.)

4. 설정(Settings) 변경 및 저장

등록된 기기를 대상으로 저장 폴더, 태그 이름 등을 설정할 수 있습니다.

⚠️ 매우 중요: 설정(Settings) 항목을 변경한 후에는 반드시 [설정 저장 (Save Settings)] 버튼을 클릭해야만 변경 사항이 반영됩니다. 저장하지 않은 상태로 기기를 조작할 경우 앱이 올바르게 동작하지 않을 수 있습니다.

5. 다양한 사용 시나리오 예시

▶ 시나리오 A: 앱이 이미 실행 중일 때 카메라를 연결할 경우 (기본 흐름)

  1. 트레이 아이콘이 있는 상태에서 카메라 USB를 PC에 연결합니다.
  2. 자동으로 앱 UI 창이 나타나고, 카메라 연결이 감지(Detection)되었음을 보여줍니다.

▶ 시나리오 B: UI 창을 수동으로 열어두고 연결할 경우

  1. 시스템 트레이 아이콘을 우클릭하고 Open UI를 클릭하여 앱 화면을 미리 띄웁니다.
  2. 그 후 카메라 USB를 연결하면, 열려있던 앱 화면에 카메라 감지(Detection) 상태가 즉각 반영됩니다.

▶ 시나리오 C: 자동 기능 (체크박스 옵션 활성화 시)

※ 참고: 아래 옵션들은 '등록된 기기'에만 동작합니다.

  • Auto-fetch 체크 시:
    카메라 USB 연결 ➔ 앱 UI가 자동으로 팝업 ➔ 기기 감지 ➔ (별도 클릭 없이) 즉시 사진 파일 가져오기(file-fetch) 단계로 자동 진행됩니다.
  • '가져온 다음 항상 장치에서 지우기' 체크 시:
    Auto-fetch를 통해 사진 가져오기가 성공적으로 완료된 후, 자동으로 카메라 내부의 원본 파일 삭제 작업이 백그라운드에서 실행됩니다. 저장소 용량을 별도로 관리할 필요가 없어 매우 편리합니다.

6. 앱 업데이트 방법

  • 앱은 4시간마다 백그라운드에서 자동으로 최신 버전이 있는지 확인합니다.
  • 새로운 버전이 감지되면 앱 화면(또는 알림)에 업데이트 안내 팝업이 나타납니다.
  • 안내에 따라 [업데이트] 버튼만 클릭하면, 최신 버전 자동 다운로드 ➔ 파일 덮어쓰기 ➔ 자동 재시작까지 한 번에 진행됩니다.

7. Windows 윈도우 시작 시 자동 실행 (AutoRun) 설정 방법

기본적으로 앱은 윈도우 시작 시 자동으로 실행되지 않습니다. 만약 PC를 켤 때마다 앱을 자동으로 백그라운드에 띄우고 싶다면 다음 명령어를 사용하세요.

  • 자동 실행 등록하기 (Add):
    명령 프롬프트(CMD) 또는 PowerShell을 열고 앱이 있는 폴더로 이동한 뒤 아래 명령어를 입력합니다.
    .\DSLR_FileTransfer.exe --add-startup
    성공적으로 등록되면 팝업 메시지가 나타납니다.
  • 자동 실행 해제하기 (Remove):
    더 이상 윈도우 시작 시 자동 실행하고 싶지 않다면 아래 명령어를 입력합니다.
    .\DSLR_FileTransfer.exe --remove-startup
